# M1 — Room

**Needs:** M0. **Goal:** draw a room and see it in 3D.

## Tasks

- [x] 2D plan editor: click to place wall endpoints, grid snapping, endpoint snapping, typed lengths.
- [x] Extrude walls to `wallHeight`; generate the floor from the closed wall loop.
- [x] Split view or toggle between plan and 3D; dimensions shown in meters or feet.
- [x] Design store (Zustand) with the `room` part of the schema in `src/model/`.

## Acceptance criteria

- A 4 × 5 m rectangular room can be drawn in under a minute.
- The 3D walls match the typed dimensions within 1 cm (unit test on the geometry).
- An L-shaped room produces a correct floor.
- Build, unit tests and smoke test pass.
