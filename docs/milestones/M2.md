# M2 — Openings and surfaces

**Needs:** M1. **Goal:** doors, windows and wall/floor materials.

## Tasks

- [ ] Doors and windows as openings on a wall, positioned by offset, width, height and sill; cut with `three-bvh-csg`.
- [ ] Openings can be added, moved along the wall and resized in the plan view.
- [ ] Floor and wall materials from a small set of CC0 PBR textures (e.g. Poly Haven); licenses recorded.

## Acceptance criteria

- A door and a window render as real holes, visible from both sides.
- An opening cannot extend past its wall's ends or above the wall height.
- Changing one wall's material updates only that wall.
- Build, unit tests and smoke test pass.
