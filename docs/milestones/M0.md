## Acceptance criteria

- The deployed site shows the chair and it can be orbited.
- A design JSON round-trips through the API unchanged.
- An unauthenticated write returns 401 or 403.
- The page loads on a phone.
- `npm run build`, `npm test` and `npm run test:e2e` pass.
