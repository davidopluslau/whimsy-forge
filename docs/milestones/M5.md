# M5 — Persistence

**Needs:** M2, M4. **Goal:** never lose work; keep old designs readable.

## Tasks

- [ ] Autosave 2 seconds after the last change; a save indicator (saved / saving / error).
- [ ] Design list: create, rename, duplicate, delete.
- [ ] `migrate()` with tests; refuse to open a design from a newer schema with a clear message.

## Acceptance criteria

- Closing the tab mid-edit loses at most the last 2 seconds of work.
- A v1 fixture still opens after a test schema bump to v2.
- Build, unit tests and smoke test pass.
