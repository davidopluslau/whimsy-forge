# M4 — Placement and editing

**Needs:** M1, M3. **Goal:** furnish a room.

## Tasks

- [x] Drag from the catalog into the room; items land on the floor.
- [x] Select, move and rotate (Y axis) with gizmos; arrow-key nudging; delete; duplicate.
- [x] Wall-mounted items snap flush to the nearest wall and slide along it.
- [x] Pictures and rugs from an uploaded photo plus a typed width.
- [x] Undo/redo for every change, via a command pattern over the Design store.
- [x] Overlap warning when two floor items intersect.

## Acceptance criteria

- Furnish a room with 10 items, hang 2 paintings, place a rug, and undo all of it step by step.
- Every edit is reflected in the Design JSON (unit tests on the commands).
- `docs/SYSTEM_DESIGN.md` is up to date with any architecture changes in this milestone, including its row under "Planned architecture", before the branch is pushed.
- Build, unit tests and smoke test pass.
