# M6 — Sharing

**Needs:** M5. **Goal:** send a design to anyone.

## Tasks

- [ ] "Share" writes a snapshot and copies a `/v/<snapshotId>` link.
- [ ] Read-only viewer: no editing UI, touch orbit, camera presets, works without login.
- [ ] "Export image" saves a PNG of the current view.
- [ ] Open Graph tags so a shared link shows a preview image in messaging apps.

## Acceptance criteria

- A link opened in a private window on a phone shows the design.
- Later edits do not change an already-shared snapshot.
- Viewer routes need no login; editor and write routes still do.
- `docs/SYSTEM_DESIGN.md` is up to date with any architecture changes in this milestone, including its row under "Planned architecture", before the branch is pushed.
- Build, unit tests and smoke test pass.
