# M3 — Catalog and asset pipeline

**Needs:** M0 (can run alongside M1–M2). **Goal:** a personal furniture catalog fed by one import command.

## Tasks

- [x] `scripts/import-asset.ts`: takes a GLB or image; normalizes to meters with the pivot at bottom center; compresses with `gltf-transform`; renders a thumbnail; uploads to R2; appends to `catalog.json` with license and source URL.
- [x] Catalog panel: search, categories, thumbnails.
- [x] Seed with 15–20 CC0 pieces: sofa, chairs, tables, bed, shelves, lamps, plants.

## Acceptance criteria

- Importing a new model is one command.
- Every seed asset loads at correct real-world size (e.g. a dining chair seat is 0.40–0.50 m high).
- Every catalog entry has a license and source URL.
- `docs/SYSTEM_DESIGN.md` is up to date with any architecture changes in this milestone, including its row under "Planned architecture", before the branch is pushed.
- Build, unit tests and smoke test pass.
